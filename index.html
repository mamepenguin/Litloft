What's new in 0.9

Video and Reading pages, Smart Collections and panels under the player

Versions 0.8 and 0.9 add pages for videos and books, saved searches you can use across the app, and more ways to search and read file contents. Here are the main changes.

Apps

Video and Reading pages

Each drive has a Video page and a Reading page for PDFs, EPUBs and archives. On Video, Discover shows Continue, New and, with the Intelligence addon, Recommended; on Reading, Continue reading, Not read yet and New. Library walks your folders and filters by name, tag and watched or read state, with grouping and sorting remembered per target.

Collections

Smart Collections

Save a search as a Smart Collection. Use it in a query with in:, as the target of the Video and Reading pages, or as a shortcut on Home. Collections and Smart Collections can be played in order and, with the Intelligence addon, asked about.

Search

More search operators

Exclude with -, as in tag:trip -tag:2023. New operators include has:tag, has:collection and modified:, alongside size and length. The + Filter menu adds them without typing the syntax.

Player

Panels under the player

Transcript, Scenes, Detailed summary and Note open under the player, two at a time, or in a column beside it on a wide window. Focus mode hides the header and sidebar so the file and its panels have the room.

Playback

Watched parts

A band above the seek bar and the bars on cards show which parts of a video you have watched. A button, or P, jumps to the parts you played most.

Read

Highlights and Office files

Select text in a PDF, Markdown note or text file to keep a highlight. Word and Excel files open in the page as read-only documents and spreadsheets with sheet tabs.

Intelligence addon

Text in pictures and video frames

Text in screenshots, slides, video frames and scanned PDF pages is read and becomes searchable. You can correct a reading, and the original result is kept so you can restore it.

Intelligence addon

Find in a file and search by an image

⌘F on a file page lists every place a word occurs: speech, on-screen text, PDF pages and body text. Paste or drop an image to find similar pictures, video scenes and documents containing its text.

Intelligence addon

Ask about what a video shows

With a model that can read images, a question about a video also sends a few of its frames, and the model can request more moments when needed. Questions about a file can continue with follow-up turns.

Watch and listen

Media playback with transcripts

Add a folder to Litloft and access its files in a browser from a phone, tablet or computer on your LAN. Videos resume from your last position. Chapters sit beside the player, and a timestamped transcript opens under it.

  • Resume playback, subtitles, chapters and seek-bar previews
  • Watched parts on the seek bar, and Transcript, Scenes, Detailed summary and Note panels under the player
  • Transcription using local Whisper or your chosen cloud speech-to-text service
  • LLM-generated chapter suggestions, applied only after you approve them
  • YouTube and Vimeo video references stored as .loft files for embedded playback

Read

Browse PDFs, photos and archives

Documents use the same layout as videos. Browse PDF thumbnails in the Pages tab or read in a full-screen page-turning view. Photo folders preserve the original aspect ratio of each image.

  • PDF zoom, fit-to-width display, page thumbnails and support for reading direction

  • EPUB books reflow to the page, including vertical Japanese text, with a contents list and text settings

Search · Intelligence addon

Search file contents and check sources

Search covers filenames, folders, transcripts, document text and what images show. Ask sends relevant passages to an LLM and returns an answer with numbered citations. Each citation links to the source file and, where applicable, the relevant timestamp.

  • Combined keyword and semantic search in SQLite, with no separate vector database required
  • Search operators such as tag:, in: and modified:, and searches saved as Smart Collections
  • Text read from screenshots, video frames and scanned PDF pages; search by an image
  • Ask in one language and receive answers citing transcripts in another
  • Save an answer and its citations as a Markdown note

Ask and summaries send relevant passages to your configured LLM. Use a local model through Ollama to process them on your own computer or server. Search and transcription do not require an LLM.

Write · Knowledge addon

Markdown notes alongside your files

Notes are stored as Markdown files in your drive folders and can be opened in Obsidian or other editors. In Litloft, use [[wiki links]] to connect notes and add links to the videos and documents you cite.

  • Edit, Split and Preview modes, autosave, and a properties card for frontmatter

  • Web clipping to Markdown and a graph of connections between notes and files
  • Generated summaries become notes only when you save them
  • Notes and Clips pages list notes you are writing and web clips you have not read yet

Import · Media Import addon

Follow channels without downloading videos

Add a YouTube or Vimeo URL, or subscribe to a channel or playlist. Litloft saves the title, thumbnail and available captions, then plays the video using the source site's embedded player. Captions can be searched and used by Ask, just like local file content.

  • Scheduled syncing for channel and playlist subscriptions
  • New videos from subscriptions appear on the Video page under New from subscriptions and Regular sources
  • Recent activity lists each import, and failed items can be retried
  • Enable or disable imports for each drive

On your phone

The same library on your phone

All screens adapt to mobile devices. Add Litloft to your home screen to use it in a standalone window. The iOS app, available to build from source, also supports audio playback while the screen is locked and picture-in-picture video.

  • Use HTTPS when accessing Litloft in Safari on iPhone or iPad
  • Connect through a VPN such as Tailscale when away from home
How it works

File storage and search indexing

Litloft reads files from your existing folders without moving them. Search indexes are stored in a local SQLite database.

Use your existing folders

  • Host folders mounted into Docker serve as drives
  • Notes are stored as .md files; imported video references use .loft files
  • New uploads, iPhone shares and web clips wait in the Inbox until you file them
  • Press N on any page to write a quick note into a folder you choose
  • Deleted files stay in Trash for 30 days; history is retained for missing files until they are detected again

Optional search indexing

  • Audio and video transcription with faster-Whisper or your chosen cloud provider
  • Text embeddings for passages from subtitles, PDFs and text files
  • Image and video frame embeddings using SigLIP2 or CLIP
  • Full-text search with SQLite FTS5 and vector storage with sqlite-vec

Access control for each drive

  • Drives are put in access groups, and a password unlocks one or more groups
  • Search, tags, favorites and Ask are limited to the current drive
  • Addons and individual features can be enabled or disabled for each drive
  • Locked drive names remain hidden until the drive is unlocked

Addons

Add the features you need

Litloft includes file browsing, playback and filename search. Addons provide content search, notes and other features. Each addon has its own repository and can be enabled separately for each drive.

Recommended

Intelligence

Adds transcription, semantic search, scene and image search, text reading from pictures and video frames, Ask with citations, summaries, and tag and chapter suggestions. LLM features connect to Ollama or an OpenAI-compatible API.

Notes

Knowledge

Adds a Markdown editor with live preview, a version history panel, Notes and Clips pages, web clipping and the capture basket. A graph shows connections between notes and files.

Sources

Media Import

Saves YouTube and Vimeo URLs as .loft files. Supports channel and playlist subscriptions, caption imports and an import log.

Backup

Cloud Sync

Schedules drive backups using rclone. Destinations include S3, Backblaze B2, Google Drive and other services supported by rclone.

iOS app

An iOS wrapper for the web app, built from ios/ in Xcode. Supports background audio, lock-screen controls, picture-in-picture video and AirPlay, and adds Litloft to the share menu for web pages, text, photos and files. The app is not distributed through the App Store.

MCP server

Allows MCP clients such as Claude Desktop to search, read, tag, rename, move and edit files, read PDF, Office and EPUB text, and search video scenes through the Litloft API. The same drive permissions apply as in the browser.

Setup

Install in four steps

Installation requires Git, Docker with Compose v2, Python 3 and approximately 5 GB of free disk space. All other dependencies run inside the containers.

Clone the repository

Addons are managed as Git submodules. Use the following command to clone them with the main repository.

$ git clone --recurse-submodules https://github.com/mamepenguin/Litloft $ cd Litloft

Run configure.py

Follow the prompts to configure the Docker environment. Press Enter at any prompt to accept the default value.

$ python3 configure.py
> py -3 configure.py
  • 1Specify the host folders to mount as drives and a short identifier (slug) for each. Display names are set later.
  • 2Choose a port. The default is 3000.
  • 3Choose whether to enable Intelligence (default: yes). The LLM_API_KEY is optional and can be left blank when using a local model.
  • 4Choose whether to enable Knowledge (default: no). Media Import and Cloud Sync are not asked about here. Media Import is turned on per drive in the setup wizard, and Cloud Sync is set up in Settings after you mount your rclone config.

The script creates docker-compose.override.yml and .env. It asks for confirmation before overwriting existing files.

Start the containers

configure.py can start Litloft after configuration is complete. The initial build takes several minutes.

$ docker compose up -d --build # To update: $ git pull --recurse-submodules && docker compose up -d --build

Complete setup in your browser

Open the address shown by configure.py, such as http://localhost:3000/setup?token=…. Follow the setup wizard to name your drives, set passwords and access groups, and select addons for each drive. You can change these settings later at /admin/settings.

Using an LLM

Summaries, tag and chapter suggestions, and Ask require an LLM. Search and transcription work without one. Select your provider and model in the browser after completing setup.

To run a model locally, install Ollama on the host and download a model. LLM processing then takes place on your own computer or server. To use an OpenAI-compatible API, set its key in .env. In this case, file text is sent to the configured API during indexing and when you ask questions.

See the installation guide for detailed instructions, including HTTPS configuration for iPhone and iPad.

Before you install

Supported use and limitations

Litloft is a personal project developed for home use. Bug reports and contributions are welcome through GitHub issues and pull requests. Support is provided as time permits.

Litloft is intended for use on your LAN or through a VPN. Authentication is minimal, so direct exposure to the public internet is not recommended.

User accounts are not supported. Profiles use nicknames set in the browser.

Video transcoding and metadata retrieval from online databases, as offered by Plex, are not supported.

Both the browser and the app require a connection to the server. Offline browsing and playback are not supported.
