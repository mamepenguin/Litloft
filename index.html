Use cases

For media-heavy knowledge work

Litloft is not trying to replace a movie server or a cloud notebook. It is a local workspace for source material you need to search, cite, and connect.

Conference videos

Find the few seconds that matter

Transcribe long talks, search across transcripts, and jump back to the cited timestamp instead of rewatching an entire session.

Documents and books

Keep PDFs beside your notes

Index documents and scanned-book archives alongside video and audio, then connect findings to Markdown notes with shared tags.

Web media

Track sources without filling storage

Add videos from YouTube, SoundCloud, or Vimeo by URL. Use embedded playback while captions and transcripts join your searchable library.

Cited Search

Ask questions, then inspect the sources

The optional Intelligence addon searches transcripts, document text, metadata, and embeddings together. When an LLM is used for Q&A, answers are linked back to the retrieved clip, page, or note.

  • Search across video transcripts, PDFs, text files, subtitles, tags, and filenames
  • Answers include citations to the retrieved sources; unknown file IDs are dropped
  • Works with local or remote OpenAI-compatible LLM endpoints; local models are recommended for private libraries
Hardware note: Indexing is CPU-intensive. Whisper transcription requires 0.5-3 GB RAM depending on the model you choose. Plan for at least 2 GB free RAM when running the Intelligence addon.

Connected Notes

Turn findings into Markdown notes

The optional Knowledge addon adds Markdown notes inside Litloft. Create a note from a file detail page, link back with [[file:...]], and keep notes searchable beside the media and documents they came from.

  • Tags are shared with core file tags, so notes and files use one vocabulary
  • Ask can cite both source media and saved Markdown notes
  • Built-in web clipper saves articles as Markdown notes
  • Generated summaries become notes only after you review and save them; Litloft never writes AI output to disk on its own
localhost:3000 › Knowledge
Media Import

Bring web videos into the same library

Add videos from YouTube, SoundCloud, or Vimeo by URL. Litloft keeps playback embedded when possible, while captions and transcripts can be indexed with the rest of your local library.

  • Add individual videos by URL without manually downloading media files first
  • YouTube captions can be reused by the Intelligence addon for search and Q&A
  • Imported media lives beside local videos, PDFs, images, and notes in the same browser UI

Setup

Up and running in minutes

Git, Docker, and Python 3 are the only prerequisites. Everything else runs inside containers.

1

Clone the repository

Use --recurse-submodules to include the bundled addons (Intelligence, Knowledge, Cloud Sync) in one go.

git clone --recurse-submodules https://github.com/mamepenguin/Litloft
cd Litloft
2

Wire the containers

configure.py is a short bootstrap script. It asks only what the containers need in order to start — which host directories to mount, the port, and which addons to run. Re-run it any time you change mounts or the port.

python3 configure.py
py -3 configure.py
①
Drive mounts For each drive, the host directory to mount and a short slug (a path identifier, not a display name). You give drives their names and access groups later, in the browser.
②
Port The default port is 3000. Change it if you need to run multiple instances or avoid a conflict.
③
Addons optional Enable the Intelligence and/or Knowledge services (yes/no). Their features — Whisper model, embeddings, LLM provider, notes — are configured later in the browser.

configure.py writes docker-compose.override.yml and .env, and creates empty drives.json / passwords.json that the app fills in. It does not ask for drive names, passwords, or LLM settings — those are set in the browser on first launch. At the end it offers to start the containers immediately (defaults to yes).

3

Start Litloft

configure.py starts the containers automatically at the end (the first build takes a few minutes). If you skipped that prompt or need to restart later:

docker compose up -d --build
# Open http://localhost:3000 when ready
4

Set up in your browser

Open http://localhost:3000. On first launch Litloft shows the /setup wizard: it lists the drives it detected from your mounts so you can name them, set passwords and access groups, and choose which optional Intelligence features to enable. Everything here can be changed later at /admin/settings.

Using LLM features (Intelligence addon)

Tag suggestions, generated summaries, and Ask answers require an LLM. Set it up after launch; search and transcription can still run without one.

  • Local (recommended) Install Ollama on your host and pull a model. Point Litloft at it with the API key / base URL in .env; the provider and model are chosen in the browser. Your source material stays on your machine.
  • API Use OpenAI, DeepSeek, or any OpenAI-compatible endpoint. Put the API key (and base URL) in .env and pick the model in the browser. File content is sent to the API during indexing and Ask queries.

Semantic search and transcription work without an LLM. Only text generation features are gated behind it, and generated summaries require an explicit review/save step before they become notes.

Extensible

Install only the services you need

Each addon is an independent service you enable via Docker Compose. Keep a simple media library, or add indexing, notes, import, and backups as needed.

Intelligence

Transcript indexing, semantic search, Q&A, tag suggestions, and summaries. LLM features work with OpenAI-compatible endpoints; local models are recommended.

Knowledge

Markdown notes linked to videos, podcasts, documents, and images, with shared tags and citations from notes and source media.

Cloud Sync

Back up your drives to any cloud storage provider via rclone — S3, Backblaze, Google Drive, and more.

Media Import

Add videos from YouTube, SoundCloud, or Vimeo by URL. Keep playback embedded when possible, and let captions join search and Q&A.
