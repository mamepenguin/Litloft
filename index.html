Litloft is a self-hosted media library for videos, audio, PDFs, images and Markdown notes on your home network. Play and browse files in your browser, search transcripts and document text, and save notes alongside your source files.

What's new

Updated navigation, viewers and editing tools

This release updates the library layout and adds features for viewing files and editing notes. Here are the main changes.

Navigation

Separate Home and Library views

Home brings together Continue Watching, Pickup, Recently Viewed, Recently Added, Favorites and Liked. Library provides a dedicated view of your folder hierarchy.

Files

A consistent file layout

Videos, audio, PDFs, images, archives and Markdown files use the same layout. The file appears on the left, with an inspector on the right. Info and Related tabs are available for all files, with Transcript and Pages tabs where relevant.

PDF

Full-screen PDF reading

Browse PDFs in a full-screen page-turning view that follows the reading direction set in the file. Search results open directly to the matching page.

Photos

Photo grids with original aspect ratios

Photo folders display images in rows while preserving their original aspect ratios. In image and archive viewers, use pinch gestures, the mouse wheel or keyboard controls to zoom, and drag to pan.

Knowledge addon

Live preview and version history

The Markdown editor supports live formatting and split view. Version history records changes when you save, with diffs for each version. You can restore an earlier version or undo a restore.

Knowledge addon

Capture basket

Collect search snippets, video timestamps, PDF pages and Ask citations, then save them together in a note. Each item links back to its source timestamp or page.

Search

Quick file search with ⌘K

The quick switcher displays filename matches first. With the Intelligence addon enabled, semantic search results follow as they become available. You can open filename matches while the model is still processing.

Sources

Verified and unverified sources

Web clips and other files imported by addons are marked as unverified. They appear in search results, but Ask uses only verified files as sources for its answers.

Clients

iOS app and MCP server

The iOS app, available to build from source, supports background audio and picture-in-picture video. The MCP server gives MCP clients access to your library using the same drive permissions.

Watch and listen

Media playback with transcripts

Add a folder to Litloft and access its files in a browser from a phone, tablet or computer on your LAN. Videos resume from your last position, with chapters and timestamped transcripts displayed beside the player.

  • Resume playback, subtitles, chapters and seek-bar previews
  • Transcription using local Whisper or your chosen cloud speech-to-text service
  • LLM-generated chapter suggestions, applied only after you approve them
  • YouTube and Vimeo video references stored as .loft files for embedded playback

Search · Intelligence addon

Search file contents and check sources

Find searches filenames, tags, transcripts, document text and image content. Ask sends relevant passages to an LLM and returns an answer with numbered citations. Each citation links to the source file and, where applicable, the relevant timestamp.

  • Combined keyword and semantic search in SQLite, with no separate vector database required
  • Ask in one language and receive answers citing transcripts in another
  • Save an answer and its citations as a Markdown note

Ask and summaries send relevant passages to your configured LLM. Use a local model through Ollama to process them on your own computer or server. Search and transcription do not require an LLM.

On your phone

The same library on your phone

All screens adapt to mobile devices. Add Litloft to your home screen to use it in a standalone window. The iOS app, available to build from source, also supports audio playback while the screen is locked and picture-in-picture video.

How it works

File storage and search indexing

Litloft reads files from your existing folders without moving them. Search indexes are stored in a local SQLite database.

Use your existing folders

  • Host folders mounted into Docker serve as drives
  • Notes are stored as .md files; imported video references use .loft files
  • Deleted files stay in Trash for 30 days; history is retained for missing files until they are detected again

Optional search indexing

  • Audio and video transcription with faster-Whisper or your chosen cloud provider
  • Text embeddings for passages from subtitles, PDFs and text files
  • Image and video frame embeddings using SigLIP2 or CLIP
  • Full-text search with SQLite FTS5 and vector storage with sqlite-vec

Access control for each drive

  • Each drive can have its own password and access group
  • Search, tags, favorites and Ask are limited to the current drive
  • Addons and individual features can be enabled or disabled for each drive
  • Locked drive names remain hidden until the drive is unlocked

Addons

Add the features you need

Litloft includes file browsing, playback and filename search. Addons provide content search, notes and other features. Each addon has its own repository and can be enabled separately for each drive.

Recommended

Intelligence

Adds transcription, semantic search, scene and image search, Ask with citations, summaries, and tag and chapter suggestions. LLM features connect to Ollama or an OpenAI-compatible API.

Notes

Knowledge

Adds a Markdown editor with live preview, version history, a Notes page, web clipping and the capture basket. A graph shows connections between notes and files.

Sources

Media Import

Saves YouTube and Vimeo URLs as .loft files. Supports channel and playlist subscriptions, caption imports and an import log.

Backup

Cloud Sync

Schedules drive backups using rclone. Destinations include S3, Backblaze B2, Google Drive and other services supported by rclone.

iOS app

An iOS wrapper for the web app, built from ios/ in Xcode. Supports background audio, lock-screen controls, picture-in-picture video and AirPlay. The app is not distributed through the App Store.

MCP server

Allows MCP clients such as Claude Desktop to search, read, tag, rename and edit files through the Litloft API. The same drive permissions apply as in the browser.

Setup

Install in four steps

Installation requires Git, Docker with Compose v2, Python 3 and approximately 5 GB of free disk space. All other dependencies run inside the containers.

Clone the repository

Addons are managed as Git submodules. Use the following command to clone them with the main repository.

$ git clone --recurse-submodules https://github.com/mamepenguin/Litloft $ cd Litloft

Run configure.py

Follow the prompts to configure the Docker environment. Press Enter at any prompt to accept the default value.

$ python3 configure.py
> py -3 configure.py
  • 1Specify the host folders to mount as drives and a short identifier (slug) for each. Display names are set later.
  • 2Choose a port. The default is 3000.
  • 3Choose whether to enable Intelligence (default: yes). The LLM_API_KEY is optional and can be left blank when using a local model.
  • 4Choose whether to enable Knowledge (default: no). Media Import and Cloud Sync are enabled separately for each drive after setup.

The script creates docker-compose.override.yml and .env. It asks for confirmation before overwriting existing files.

Start the containers

configure.py can start Litloft after configuration is complete. The initial build takes several minutes.

$ docker compose up -d --build # To update: $ git pull --recurse-submodules && docker compose up -d --build

Complete setup in your browser

Open the address shown by configure.py, such as http://localhost:3000/setup?token=…. Follow the setup wizard to name your drives, set passwords and access groups, and select addons for each drive. You can change these settings later at /admin/settings.

Using an LLM

Summaries, tag and chapter suggestions, and Ask require an LLM. Search and transcription work without one. Select your provider and model in the browser after completing setup.

To run a model locally, install Ollama on the host and download a model. LLM processing then takes place on your own computer or server. To use an OpenAI-compatible API, set its key in .env. In this case, file text is sent to the configured API during indexing and when you ask questions.

See the installation guide for detailed instructions, including HTTPS configuration for iPhone and iPad.

Before you install

Supported use and limitations

Litloft is a personal project developed for home use. Bug reports and contributions are welcome through GitHub issues and pull requests. Support is provided as time permits.

Litloft is intended for use on your LAN or through a VPN. Authentication is minimal, so direct exposure to the public internet is not recommended.

User accounts are not supported. Profiles use nicknames set in the browser.

Video transcoding and metadata retrieval from online databases, as offered by Plex, are not supported.

Both the browser and the app require a connection to the server. Offline browsing and playback are not supported.
