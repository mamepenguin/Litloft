# Values the secret scan must not report. One entry per line:
#
#    <path-glob> | <pattern> | <reason>
#
#    path-glob  which changed files the entry covers; * also matches /.
#    pattern    matched against the value the scan found.
#    reason     required: why the value is not a secret. An entry without one is an error.
#
# Nothing is allowed by default. Allow a value only when it is known not to be a credential
# (a fixture, a documented example); an unfounded entry is a prohibited change.
#
# Example. Remove the leading `#   ` to use it.
#
#   tests/fixtures/** | EXAMPLE_TOKEN_[0-9]+ | fixed fixture value, not a credential
