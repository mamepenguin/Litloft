推しを H2 → H3 に更新。「旧版の魅力の本丸」仮説を再検証した結果、本命は thead 無色 だった可能性が高い。table は既に (i) 水平 divider、(ii) thead tint、(iii) 行背景色（展開時）、(iv) accordion border の 4 レイヤーで情報を載せている。thead の tint を外すと 4 → 3 に減って「静かに検証できる読み物」に近づく。bottom border + font-weight だけで header の役割は十分通じる（Apple HIG / Medium 等の editorial table も同じ手法）。H3 は「旧の静けさ」と「16px 可読性」を両立する最も倹約的な組み合わせ。

Markdown 要素カタログ側の table も thead 無色に追従（本 HTML では既に .reading-A thead th を background: transparent に修正済み）。根拠: (1) MarkdownPreview は detailed_summary と共通 typography で統一する方針（前 revise で確定）、ここだけ differentiate すると context 切替で thead の色が変わるブレが発生、(2) DESIGN.md §6「Depth is expressed through surface color differences and border-radius — not box-shadow」は逆にいえば surface の色差は depth 表現に温存すべきで、table header のような構造要素に消費しない方が筋が通る。detailed_summary / MarkdownPreview / 将来の Knowledge preview いずれも thead 無色・下境界線のみ で統一。

DESIGN.md 準拠まとめ: accordion / card = rounded-xl、button / badge / chip / toggle = rounded-2xl、amber は weak accordion 外枠の border-dashed で運用（§2.2 準拠）、scale() hover なし（§4）、tracking-wider は英語固定ラベルのみ（§3.3）、dark は warm plum、focus-ring は var(--focus-ring)。

Dot slot 予約（横ズレ防止）: .dot は常に width:14px; height:14px; margin-left:6px を持つ固定スロット。Verify OFF と data-tier="missing" では visibility: hidden（display:none ではなく）でボックスだけ残す。これで表の最右カラム幅が on/off 切替で 1px も動かず、段落の text-wrap も Verify 状態に依存しない。全 segment（strong / weak / missing）が同じ slot を持つ前提で実装。

UI から撤去した要素: (1) top_score 数値バッジ、(2) adjacent chip + 抜粋内の ex-adjacent 下線強調。tier は dot（色・形・dashed ring）+ accordion 内の単一 chip（● strong / ◐ weak）のみで伝える。抜粋本文は prefix (muted) / target (highlight) / suffix (muted) の 3 区分に簡素化。adjacent chunk は retriever 内部の実装詳細として、UI には現れない（本文の一部として suffix に溶かす）。
