# Litloft

**家のファイルを、家のサーバーで、美しく。**

自宅LANで動くオープンソースのファイル管理・メディアストリーミングアプリ。クラウドに頼らず、Docker 1コマンドで起動する。

---

## なぜ Litloft？

あなたのファイルは、あなたの手元に置くべきです。

- **プライバシー完全保持** — データが自宅のサーバーから出ない。クラウドへの送信なし
- **Docker でそのまま動く** — `docker compose up` で起動。複雑なセットアップ不要
- **ブラウザだけで使える** — アプリのインストール不要。スマホからも同じ URL でアクセス

---

## できること

### 動画・音楽・画像を楽しむ

**動画ストリーミング**
シーク対応のブラウザ内プレーヤーで再生。字幕（SRT/VTT）の表示、キャスト（TV への送信）、レジューム再生に対応。前回どこまで見たか自動で記録する。

**音楽再生**
アルバムやプレイリストをまとめて再生。ループ・シャッフル対応。

**画像ギャラリー**
フォルダ内の画像をスライドショーで閲覧。見開き表示

---

### ファイルをブラウザから管理する

**アップロード**
ドラッグ＆ドロップ、またはボタンからアップロード。フォルダごとまとめてアップロードし、フォルダ構造を保持する。最大 2GB のファイルに対応。

**整理・操作**
リネーム、移動、コピー、削除をブラウザから操作。複数ファイルを選択して一括操作も可能。テキストファイルはブラウザ内で直接編集できる。

**ゴミ箱**
削除はまずゴミ箱に入り、30日後に自動削除。誤って消してしまってもすぐ元に戻せる。

**見つからないファイル**
NAS が一時的にオフラインになっても、視聴履歴・タグ・AI データはそのまま保持。ドライブが戻れば自動で復活する。

---

### ドキュメントを読む

PDF、Word、Excel、PowerPoint、テキスト、Markdown をブラウザ内でプレビュー。

**Markdown 対応**
シンタックスハイライト、タスクリスト、Mermaid 図（フローチャート・シーケンス図等）をそのまま描画。

**ZIP ファイル**
中身の一覧を表示し、個別のファイルを取り出せる。Shift_JIS ファイル名も正しく扱う。

---

### 整理・検索する

**タグ**
ファイルにタグを付けて分類。ドライブ内のタグ一覧から絞り込み検索できる。Markdown ファイルは frontmatter の `tags:` と自動連携。

**お気に入り・ピン留め**
よく見るファイルにスターを付け、よく使うフォルダをピン留め。サイドバーからワンクリックでアクセス。

**プレイリスト**
ユーザー作成のプレイリストでコンテンツをまとめる。フォルダをそのままプレイリストとして連続再生することも可能。

**検索**
ファイル名での全文検索。スマートフォルダ（検索条件の保存）でお気に入りの絞り込みを名前を付けて保存できる。

**視聴履歴**
最近見たファイル、続きを見る（再生途中の動画一覧）を自動管理。ニックネームで複数デバイスの履歴を共有できる。

---

### アクセス管理

**マルチドライブ**
「家族ビデオ」「音楽」「プライベート」など用途別にドライブを分けて管理。ドライブはセキュリティ境界として完全に独立。

**パスワード保護**（オプション）
ドライブ単位でパスワードを設定。特定のドライブだけパスワードで保護するといった使い方ができる。パスワード未設定時はすべて公開（家庭内LANでの気軽な使い方）。

**管理者機能**
ブラウザから GUI でドライブの追加・削除、パスワード管理、アドオンの設定が可能。ドライブの容量・ファイル数・システム状態を一覧するダッシュボードも付属。

---

### 重複ファイルの検出

ハッシュベースで重複ファイルをグループ化し、無駄に使っているストレージ量を表示。一目でどれを削除すべきか判断できる。

---

## アドオンで機能を拡張する

Litloft はアドオンシステムで機能を後から追加できる。不要な機能を最初から抱え込まずに済む。

### intelligence — AI で検索・整理

独立した Docker コンテナで動く AI 拡張。OpenAI 互換 API（ollama で完全ローカル動作も可能）を使用。

| 機能 | 説明 |
|------|------|
| **自動文字起こし** | Whisper で動画・音声を自動でテキスト化。字幕として動画に重ねて表示 |
| **セマンティック検索** | 意味で検索。「元気が出る曲」「料理の動画」のような自然な言葉で見つかる |
| **Ask（自然言語Q&A）** | 「先月見た映画で SF のはどれ？」などの質問に引用付きで回答 |
| **AI 要約** | ファイルの内容を短い文章・詳しい Markdown でまとめる。編集・復元対応 |
| **タグ提案** | 内容を分析してタグを自動提案。承認するまで適用されない |
| **CLIP フレーム検索** | 動画の特定シーン（「猫が走っているシーン」等）をキーワードで検索 |

### knowledge — Markdown ノート

ファイルにメモを紐付ける Markdown Vault と、Web クリッピング機能。

### downloader — URL からダウンロード

yt-dlp を使って YouTube などの URL からメディアをダウンロード。ダウンロードせず URL として登録（LoftRef）すれば、字幕・メタデータだけ取得して intelligence で検索対象にもできる。

### podcast — フォルダを Podcast に

フォルダを Podcast RSS フィードに変換。好みの Podcast アプリで音声ファイルを購読できる。

### cloud-sync — クラウドバックアップ

rclone を使ってドライブの内容をクラウドストレージに定期バックアップ。

## ユースケース

### 家族のビデオライブラリ

家族で撮った動画を「家族ビデオ」ドライブに入れておく。スマホからアクセスして再生できる。子どもたちには「プライベート」ドライブを見せずに、「家族」ドライブだけパスワードなしで公開できる。

### 自分のメディアコレクション

映画・ドラマ・音楽をジャンル別にドライブを分けて整理。intelligence アドオンを有効にすれば、字幕が自動生成され、「5年前に見た SF 映画」もキーワードで見つかる。

### 自炊した書籍・PDF 管理

PDF や自炊した書籍を整理。タグやお気に入りで分類し、ブラウザから直接読める。

### 作業用ファイルのホームサーバー

NAS の代わりに使う。複数デバイスからアップロード・ダウンロードし、ファイルをフォルダ・タグで整理する。テキストファイルはブラウザから直接編集もできる。

### Podcast スタジオ

録音した音声ファイルを Podcast アドオンで RSS に変換。家族・グループで音声コンテンツを配信できる。

## UI の特徴

- **ダーク / ライトテーマ** — システム設定に追従する「自動」モードも選べる

## クイックスタート

### 方法A — 対話型セットアップ（推奨）

```bash
python configure.py
docker compose up -d --build
```

対話式スクリプトがドライブ・パスワード・アドオン設定を質問し、`docker-compose.override.yml` などの設定ファイルを自動生成する。ブラウザのセットアップウィザードは自動的にスキップされる。

### 方法B — 手動セットアップ

**1. 設定テンプレートをコピー**

```bash
cp docker-compose.override.yml.example docker-compose.override.yml
```

`docker-compose.override.yml` を編集してドライブをマウントする:

```yaml
services:
  backend:
    volumes:
      - /path/to/your/videos:/app/drives/videos
      - /path/to/your/music:/app/drives/music
      - ./data:/app/data
```

**2. 起動**

```bash
docker compose up -d --build
```

`http://localhost:3000` を開く。LAN 内の他のデバイスからは `http://<ホストIP>:3000`。

**3. セットアップウィザード**

初回起動時にブラウザが `/setup` に誘導される。6ステップのウィザードに従って、ドライブの設定とアクセス制御を設定するだけで完了。
