1. 何ができるか

ドライブごとにファイルを閲覧し、動画・PDF・EPUB・ノートを同じ画面で開ける。フォルダ一覧、コレクション、受信箱から目的のファイルへ移れるp.4。

2. 検索

ファイル名・タグ・本文を横断して探す通常の検索と、意味で探すハイブリッド検索がある。結果は抜粋付きで表示されるp.12。

12 ページ

3. ノート

Markdown のノートはその場で編集でき、保存は自動で行われる。保存に失敗すると表示で知らせるp.21。
