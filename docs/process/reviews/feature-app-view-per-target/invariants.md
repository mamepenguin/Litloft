I20. (r1) The shared `ToolbarMenu` keeps an outlined menu's leading icon at 16px when its value is cut, and changes nothing else about how any other caller draws (the quiet menus keep their truncating value).
I20. (r2) The shared `ToolbarMenu` keeps an outlined menu's leading icon at 16px when its value is cut; the Video and Reading shelf-page quiet sort menus draw their whole value without an ellipsis; every other quiet menu keeps its truncating value, and nothing else about how any other caller draws changes.
I13. (r4) In Notes and Clips, a Target choice made on the Library or a shelf page removes the view parameters from the URL by replace (Clips `group` and `sort`, Notes `sort`; Notes keeps `folder`, `tag` and `q`), and once the new Target is in force and the Library body is drawn the fill-in writes that Target's resolved view by replace; neither adds a history entry, and no Library body request is sent with the previous Target's view after the choice. The fill-in changes nothing in a URL that already has readable `group` / `sort` (Clips) or `sort` (Notes). A fallback to `default` on load and a member re-evaluation leave the URL as it is; a chosen Target that falls back to `default` shows the `default` Target's stored view.
