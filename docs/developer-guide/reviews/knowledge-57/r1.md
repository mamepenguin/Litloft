## Findings

### F1 [introduced] Search highlight disappears for Greek titles with a word-final capital Σ — medium-low, breaks the intent of R-0 #5 (outside its literal "length changes" scope)

`lowercaseWithOffsets` lowercases **one code point at a time** (`NoteRow.tsx`, `for (const char of text) … char.toLowerCase()`), while the needle is lowercased **as a whole string** (`needle.toLowerCase()`). V8 applies Unicode Final_Sigma only in whole-string context: `"ΟΔΟΣ".toLowerCase()` is `"οδος"` (final `ς`), per-code-point it is `"οδοσ"`. The two sides no longer agree, so `indexOf` finds nothing.

Reproduction (temporary vitest probe importing `markMatches` at this SHA, beside a verbatim copy of the parent's function; probe deleted afterwards):

| title | query | this SHA | parent |
|---|---|---|---|
| `ΟΔΟΣ` | `ΟΔΟΣ` | `[]` | `["ΟΔΟΣ"]` |
| `ΟΔΟΣ` | `οδος` | `[]` | `["ΟΔΟΣ"]` |
| `ΟΔΟΣ ΚΑΙ` | `ΟΔΟΣ` | `[]` | `["ΟΔΟΣ"]` |
| `Οδός ΚΑΙ ΟΔΟΣ` | `ΟΔΟΣ` | `[]` | `["ΟΔΟΣ"]` |
| `ΟΔΟΣ` | `σ` | `["Σ"]` | `[]` |

User-reachable: the server filter is `File.title.ilike('%ΟΔΟΣ%')`; on SQLite `lower()` is ASCII-only, so an exact-case Greek query returns the row, and the row now renders with no mark. Same function also highlights the folder path (`markMatches(folder, query)`), so folder matches are affected too. Only the Final_Sigma context is affected: an exhaustive scan of all code points shows U+0130 is the only single code point whose `toLowerCase()` changes UTF-16 length, and Final_Sigma is the only context-sensitive rule `String.prototype.toLowerCase` applies.

No test covers it (NoteRow tests use Latin and `İ` only). Invariant #5 as written covers "titles whose lowercase form changes length", and `ΟΔΟΣ` does not change length — see "Is anything missing from the list".

### F2 [introduced] No test holds the offset mapping for characters outside the BMP — low (test gap), R-0 #5 intent

Mutations M23 (`offset += 1` instead of `char.length`) and M23b (iterate UTF-16 units instead of code points) both survive. M23 on a title such as `😀 ai` with query `ai` marks ` a` instead of `ai` (every offset after the emoji is one unit short); titles with emoji before the matched word are ordinary. The code at this SHA is correct (probe: `😀 ai`/`ai` → `["ai"]`, `😀😀 AI x`/`ai` → `["AI"]`, same as parent) — the finding is that the new offset table has no test with a surrogate pair before a match.

Survivors: M25 (timer does not re-arm after it fires), M31 (unmount does not `clearTimeout`), M31b (unmount does not remove the `visibilitychange` listener). Under M25 the page left open across a second midnight keeps the first rollover's day — which R-0 #7 forbids ("after local midnight passes with the page open") — and no test fails. The "midnight" test advances exactly one rollover. Under M31/M31b every Notes page visit leaks a listener and a pending timer calling `setNow` on an unmounted component. The code at this SHA does re-arm and clean up; the gap is the tests.

### F5 [introduced] Cmd/Ctrl/Shift-clicking the tag chip moves focus in the current tab without navigating — low, B

`onClick={() => listRef.current?.focus()}` runs before Next's `linkClicked`, which returns early for a modified click (`next/dist/client/app-dir/link.js`: user `onClick(e)` at ~311, `isModifiedEvent` bail-out at ~58). So opening the unfiltered list in a new tab leaves the current tab's heading chip in place but moves keyboard/screen-reader focus to the list wrapper (which has `focus:outline-none`, so sighted keyboard users see focus vanish). Invariant #4 is still satisfied (focus is inside page content), so this is B unless the supervisor considers it reachable enough. Middle-click does not fire `click` and is unaffected.

## Is anything missing from the R-0 list?

1. **#5 should not be limited to titles whose lowercase changes length.** Write it as: *a title the server returned for the query shows at least the matched characters marked, for every title the parent marked* — covering context-sensitive casing (F1, Greek final sigma) and astral characters before the match (F2). As worded, F1 is a regression the list does not forbid.
2. **#7 says "midnight", singular.** Add: *the rollover repeats every midnight the page stays open, and leaving the page leaves no timer or listener behind* (F4).
3. **#8 has no "ends" clause.** Add: *Show more disappears exactly when the pages read cover the server total — no extra empty page, no early stop* (F3 in NoteResults; the AllNotes copy is held).
