## Q2: what did it break?

Per source type, against the spec's intent (no retelling in source order, no agentless passives, named attribution on opinions only):

- **Evaluative (reviews), the main production case:** nothing reopens. The Evaluative note ("Always attribute evaluations to whoever made them") agrees with the long rules and requires no ordering, so most-important-first and the passive ban still apply.
- **Conversational / Explanatory (talks, interviews, lectures):** no ordering requirement. "Identify whose statement it is" names a speaker, so it is not agentless. It does override "facts: state them plainly" for facts a speaker states, and interview items will attribute facts too. That is the r1 finding 5 trade, now settled toward the common rule. It adds attribution but no agentless forms.
- **Informational (news):** this one partly reopens. The Informational note's own example of marking unconfirmed information is `"reported that ..."`, an agentless form. The precedence line names "the origin of information", and a model can reasonably read "distinguish confirmed from unconfirmed" as covered by it. For news roundups the passive ban then yields to the note's example, and 報じられている / とされている can come back on unconfirmed items. This is finding 1.
- **Documentary (report, thesis, contract):** source order returns by design (chapter structure). The spec lists only "procedural and narrative" as source-order types, so this widens the spec. It is a deliberate outcome of the fix, but the spec intent did not include it. It is part of finding 2.
- **Classification risk:** which type applies is the model's call. A review video told as a story ("I bought it, opened it, used it for a week") can be classed as Narrative, and the precedence line then licenses exactly the source-order retelling the change was meant to remove (box contents first, verdict last). Before the fix, the long rule's own exemption covered only procedures and narratives too, so this risk is not new in kind. The fix does make the precedence explicit and general, which makes it a stronger instruction. This is also part of finding 2.

None of this breaks an R-0 invariant (they are all about storage and rendering), and no test can hold it. It can only be seen in the R-5 regeneration of the 11 videos, and the list in finding 2 says what to look at.
