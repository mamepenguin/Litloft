- `type` / `file_type` が `apply_kind_filter` に届く経路: `routers/search.py` の `/search` と `/search/compare`、`routers/rag.py` の `file_type`（body）→ `rag/service.py` → `rag/retriever.py` → `search.search` → `_build_results`。Find の `file_type_hint` は `_find_kind_for_hint` を経て同じ `_build_results` に届く。`_build_results` 以外で要求 kind を `IndexedFile.file_type` と比較している箇所はない。したがって `markdown` alias はすべての入口から効く。
