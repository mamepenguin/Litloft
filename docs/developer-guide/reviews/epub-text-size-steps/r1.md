## Findings

### F1 — bucket A (suggested; see note) — [introduced]
`frontend/e2e-epub/typography.spec.ts:222` "five-percent presses › in a burst end at the last one pressed" does not hold invariant 9's clause "a burst of presses applies only its last value".
Reproduction: mutation E5 in `frontend/public/epub-reader/reader.js` — replace `if (state.turning) state.pendingTypography = t;` with a queue (`(state.q ??= []).push(t)`) drained one by one at the top of `drainPending`, so every value of the burst is applied (one restyle + goTo each). Full `pnpm test:e2e:epub`: 235 passed, 5 skipped — nothing fails. The test only checks the end state (root 13px, start still shown, no turn), which a queue also reaches. Mutation E3 (drop the gate entirely) is caught only by the pre-existing "5 ms into a seek" test, not by the new one.
The test is new in this commit, so [introduced] needs no parent run.
Note for triage: the observable cost of E5 is extra reflows/relayouts, not a wrong final page. A detector exists in the file's own pattern ("a theme change lays the book out no more than once" counts `location` messages); counting `location` posts (or restyles) across the burst would hold the clause. If the supervisor judges "applies only its last value" to be about the end state only, this is B.

### F2 — bucket B — [introduced]
`frontend/e2e-components/segmented-control.cases.ts:84-87,105` — `centreOffset` measures the value span's *box* against the midpoint of the gap between the buttons, so it holds neither "centred in the row" nor "text centred".
Reproduction: V1 (drop `flex-1` from the value span in `EpubTypographyPanel.tsx`: the span shrinks to its text and the whole row packs to the left, + no longer at the right edge) and V3 (`text-center` → `text-left`: text drawn at the left of the span) — both leave `pnpm test:e2e:components segmented-control` at 10 passed. With gap-3 on both sides the box is always equidistant from the two buttons. Measuring a `Range` over the text node (glyph box) against the row/panel centre would hold it. Not a declared invariant, hence B.
