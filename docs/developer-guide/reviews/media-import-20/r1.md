## Findings

### F1 — the panel now starts 8px under the tab underline (was 32px) `[introduced]`
- R-0 item: none.
- `addons/media_import/frontend/Page.tsx:116` (`<div className="space-y-8 px-4 pb-6">`).
- Reproduction: emulated structure above, 986px: tablist bottom 182.4, first panel
  element top 190.4 → 8px (PageHeader's `py-2` only). Parent: header and panel were
  siblings under `space-y-8` → 32px. For comparison, the other PageFrame callers put a
  top pad on their content: `DriveHome` `pt-2 sm:pt-4`, intelligence Ask `pt-2`.
  Here the Watch view's first section heading ("よく見るソース") sits 8px under the
  tab underline.
- Severity: low (B). Visual density only; no invariant broken, no test can hold it in jsdom.

### F2 — the scope line omits the count that DESIGN.md §6 names `[introduced]`
- R-0 item: none (R-0 #3 is satisfied: no number is shown that is not kept current).
- `addons/media_import/frontend/Page.tsx:92`.
- Checked the author's reason against the code: `subsCount` is set only by the mount
  effect keyed on `currentDrive`; `Composer.onCreated` bumps `refreshKey` but never
  re-reads the list, so a count on the scope line would indeed go stale after adding a
  source. DESIGN.md §6 "An unknown count shows the drive alone" makes the drive-only line
  a state the rule already allows. It matters little: the screen has two views counting
  different things (surfaced sources vs. all subscriptions), so "this screen's count" has
  no single referent either. Recorded so the triage sees it was weighed, not missed.
- Severity: informational (B).

### F3 — comment claims core does not expose tab ids; `PageTabs` takes `id` / `controls` `[pre-existing]`
- R-0 item: none.
- `addons/media_import/frontend/Page.tsx:117-122` (unchanged by b2d1765).
- `frontend/src/components/PageTabs.tsx` declares `PageTabItem.id` and
  `PageTabItem.controls`, so `aria-labelledby` / `aria-controls` binding is available.
  The comment tells a reader the stronger binding is impossible. It does not lead to a
  breaking change, only away from an improvement; remedy is deletion.
- Severity: low (B, prose).
