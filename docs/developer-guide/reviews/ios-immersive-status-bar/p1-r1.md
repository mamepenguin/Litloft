## Findings

### F1. Two requests before the next layout: the first is never answered, or is answered with the old size
- Label: `[introduced]` (code created in this commit)
- Invariant: 6 (exit / second press / unmount during `"opening"` must leave no immersive hold — the page's
  hold waits on this ack), shell side of 2. Also the plan's own contract "every `page.immersive` is acknowledged".
- Evidence: `ios/Litloft/Web/WebView.swift` `pageAsked(immersive:)` compares against `model.immersive` (the
  *requested* state), not the laid-out one; `answerAfterLayout` keeps a single `pendingAnswer`; `WebShell.swift`
  `onGeometryChange(for: Bool.self) { model.immersive }` only fires when the value SwiftUI lays out changes.
- Reproduction: P-TF above — `postMessage({type:'page.immersive',active:true}); postMessage({...active:false})`
  in one `evaluateJavaScript` -> no `page.immersive.applied` at all within 10 s. SwiftUI coalesces true->false,
  the geometry value never changes, nothing answers either request. P-TT: the second `true` hits the
  "already holds" branch and is answered immediately with `height: 812` although the web view is about to be 874.
- Direction: answer against what has been laid out (`laidOutImmersive`) rather than what was requested, and
  settle every outstanding request when a layout lands (or when the request is already satisfied by the laid-out
  state). Add a hosted test posting on/off in one turn and asserting exactly one ack per request with the final
  state.

### F2. Landscape is not tested: `.all` and the `setNeedsLayout` that the landscape ack depends on both survive
- Label: `[introduced]`
- Invariant: 8 (page must not move in landscape — `.all` reflows it, which the spec's `## Checked, no action`
  explicitly rejects) and the ack handshake (no answer = page waits; 6 / shell side of 2).
- Evidence: `ios/Litloft/Web/WebShell.swift` edges expression; `WebView.swift` `answerAfterLayout`
  `webView?.setNeedsLayout()`; `ios/LitloftTests/ImmersiveTests.swift` hosted tests run portrait only.
- Reproduction: mutation 12 and mutation 20 both leave the suite green. P-LS under mutation 20: in landscape the
  frame does not move, so no layoutSubviews happens and neither request is acked (`a=nil b=nil`). Under mutation
  12: width 750 -> 874 while immersive.
- Direction: a hosted landscape case asserting the frame is unchanged (x/width) across on/off and that each
  request is acked.

### F3. `acknowledged(_:in:)` waits for `>= count`, so duplicate / unsolicited acks pass
- Label: `[introduced]`
- Invariant: none directly (detector rule 1 in `review-workflow.md`); it is what lets mutation 5 live — a shell
  that re-sends the last ack on every later layout would reach the page as spurious acks.
- Evidence: `ios/LitloftTests/ImmersiveTests.swift` `acknowledged` (`count >= count`, returns `.last`).
- Reproduction: mutation 5 green.
- Direction: after the expected ack, settle briefly and assert the exact count (`== count`).

### F4. The black band while immersive is not held by any test
- Label: `[introduced]`
- Invariant: none (reads wrong / spec behaviour, not an R-0 item).
- Evidence: `ios/Litloft/Web/WebShell.swift` `band`; mutation 13 green.
- Direction: optional; only if the band is considered load-bearing (landscape side bands).

### F5. "An SPA navigation does not end immersive" is not held
- Label: `[introduced]`
- Invariant: 3 (a test that lets an invariant break through is an A).
- Evidence: `ios/Litloft/Web/WebView.swift` `watch(_:)` `\.url` observer; `ImmersiveTests` covers commit,
  termination and download but not a `url` change without commit (the plan lists it).
- Reproduction: mutation 22 (`setImmersive(false)` in the url observer) green.
- Direction: a coordinator test changing the page URL via `history.pushState` (or driving the observer) and
  asserting `model.immersive` stays true.

## Is anything missing from the R-0 list (shell side)?

Yes, one item: **every `page.immersive` request is answered by exactly one `page.immersive.applied` whose
`active` and size are the web view's state after the layout for the final requested state** (never a
pre-layout size, never silence). Invariants 5/6 on the page side depend on it, and F1/F2 break it without
breaking any listed line directly.
