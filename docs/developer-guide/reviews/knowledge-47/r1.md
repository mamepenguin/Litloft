## Findings

### F1 [introduced] R-0 #5 — ランディングのリンク先の `encodeURIComponent` をどのテストも保持していない

- 変異 M1: `NotesPage.tsx` の `href={\`/drive/${encodeURIComponent(drive)}/addons/knowledge/connections\`}` → `href={\`/drive/${drive}/addons/knowledge/connections\`}`。diff を確認のうえ実行、`NotesPage.test.tsx` + `connectionsPage.test.tsx` 25 tests 全 pass（生存）。
- 原因: `NotesPage.test.tsx` の drive フィクスチャが `"d"` 固定で、エンコードの有無が観測できない。`connectionsPage.test.tsx` は `"動画 d"` を使っていて戻りリンクの同種変異（M8）は殺しているので、ランディング側だけ抜けている。
- 観測可能か: 可能。drive 名に空白・非 ASCII・`#`・`?` を含むフィクスチャで href が変わる。現行コードは正しいが、R-0 #5 を壊す変更がテストを通る（R-4「A を通すテストは A」）。
- 利用者への影響（退行した場合）: `#` や `?` を含むドライブ名でリンクが別パス（フラグメント / クエリ扱い）になり、つながりページに辿り着けない。

### F2 [introduced] R-0 #5 — `next/link` であること（リロードしないこと）をどのテストも保持していない

- 変異 M4: `<Link …>…</Link>` → `<a …>…</a>`（href・className・中身は同一）。diff 確認のうえ実行、25 tests 全 pass（生存）。
- 観測可能か: 可能。`next/link` を目印付きのモックに差し替える、あるいはクリック時に `router.push` 系が呼ばれ `defaultPrevented` になることを見るフィクスチャで区別できる。現状のテストは role=link と href しか見ていない。
- 利用者への影響（退行した場合）: 入口を押すたびにフルリロードになり、SPA ナビゲーション方針に反する。

### F3 [introduced] R-0: none（#3 に従った結果として生じる） — 専用ページでグラフの見出しと折りたたみトグルがページ見出しの直下に重複して残る
