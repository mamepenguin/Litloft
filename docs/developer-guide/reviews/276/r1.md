## R-0 の不変条件に欠けているもの（初回のみ）

1 件の追加を提案する: **「guarded field で compositionend 直後の grace window 内に来た Enter / Escape 以外のキー（Backspace、矢印、文字、Tab）は飲み込まれず、1 回きりの消費も起こさない」**。現行の 3 と 5 は "outside composition" と "exactly once" しか言っておらず、grace window 中の他キーの扱いが決まっていない。変異 H9（キー条件を削除し、window 内なら全キーを飲む）は生き残る（F4）。これ以外に、ユーザーが触れる経路で不足しているものは見当たらない。7 の Enter 側は、core / addons に plain Enter のグローバルショートカットがないため、現状は実質空。
