A check that goes red on M1 is one that observes what `FolderBrowser` passes: e.g. the stand-in records its received prop keys and the test asserts the declared set (`toEqual`, detector rule 1/5), or a render through the real `FolderContent` on an empty write destination asserting the empty state's buttons are exactly `["Add files"]`.
