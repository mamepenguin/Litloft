## Findings

### F1. The F1 fix makes an import on a drive whose `url_import` has resolved false reachable from the Add menu  [introduced]

- Invariant: none broken as written. Invariant 1 speaks only of the row, and the supervisor's revision of 4 requires the dialog to survive the policy change; this finding is the consequence of that combination, supplied as material.
- `frontend/ImportFromUrlMenuItem.tsx:52-66` (commit `3c5741e`: the gate now hides the row only; the dialog stays mounted with `onImported={handleImported}`).
- Reproduction (probe P3, real `AddButton` at core 63da8e0c): policy response held pending with `url_import: false` → open Add → press the row → release the policy → row disappears → type a video URL → Import.
- Observed on `ba32f18`: `createLoft` called with `[VIDEO, "d", "videos"]`, menu closes, focus on Add. Under the pre-fix shape (mutation F1b, `if (rowHidden) return null`) the dialog is gone the moment the policy settles and nothing can be sent.
- With `url_import` not enforced server-side (already filed (a)), this is a `.loft` created on a drive whose policy the UI has already resolved to off. The window is the first policy fetch of a drive (and each 30 s TTL refetch, see probe P2) with the dialog opened inside it.

### F2. "`onDialogOpenChange` true/false stay balanced" (revised 4) is held only for Cancel; the success path while the row is hidden is not held  [introduced]

- Invariant: 4 (revision).
- `frontend/ImportFromUrlMenuItem.tsx:64`; test `ImportFromUrl.test.tsx:376-402`.
- Mutation F1l: `onImported={rowHidden ? () => { setOpen(false); onRequestClose?.(); } : handleImported}` → suite 180 passed; probes P1–P3 pass too.
- Observed under F1l: an import that succeeds after the row was hidden reports `onDialogOpenChange(true)` with no matching `false`. Expected per revised 4: `[[true],[false]]`.
- Against the real host this is inert: `AddButton.closeMenu` sets `addonDialogOpen` false and the `!menuOpen` effect clears it again, so no user-visible state at 63da8e0c depends on it. The gap is against the invariant's literal wording, which is the declared contract for any host.
