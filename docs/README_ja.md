# Litloft

ファイルベースのメディアライブラリ

Litloftは、自宅LANで動かすセルフホスト型のライブラリアプリです。動画、文書、画像、Web動画、Markdownノートをブラウザで共有できます。
元々動画サーバーとして開発を始めましたが、知識の集約、検索にも重点を置いています。ファイル内容を複数の手法でインデックス化し、散らばったメディアを使える資料として活用することを目指したアプリです。

**[Webサイト](https://mamepenguin.github.io/Litloft/)** ·

> 主に自分で使うために作っています。IssueやPRは歓迎しますが、サポートはベストエフォートです。

## Litloftを作った理由

世の中には動画の再生が得意なメディアサーバーや、文章を書くのに特化したノートアプリがたくさんあります。しかし、Litloftがターゲットにしているのは、その「すき間」の体験です。

講義の録画、配信アーカイブ、PDF、自炊本、個人的なメモ、あとで見るつもりだったリンクなど。これらをひとつのローカルライブラリとしてまとめて扱いたいと考えました。

動画を見ながら字幕を検索し、気になったことをメモに残して、別の資料と紐付ける。あとから振り返るときは、動画からでも、ノートからでも、検索結果からでも、必要な情報にすぐアクセスできる。そんな環境を作りたくて開発しました。

## メディアサーバー

Litloftの土台となるのは、ブラウザから手軽に使えるLAN向けメディアサーバーとしての機能です。

フォルダを指定すれば、スマホやPCのブラウザから直接ファイルを開けます。動画のレジューム再生（前回の続きから再生）はもちろん、画像やPDF、Markdownファイルも扱えます。ドライブごとにアクセス権を設定できるので、家族向けの動画と自分用の調査資料が混在しません。

高速なブラウジング、サムネイル表示、ストリーミング、履歴、タグ付けなど、日常的な使いやすさを何よりも重視しています。

## 中身を検索・要約する（Intelligence）

ファイルの中身をLitloft側でインデックス化し、いつでも引き出せるようにする機能です。

動画の音声を自動的に文字起こし（トランスクリプト）してテキストや字幕と一緒に読み込ませることで、「あの言葉を話していたシーン」をピンポイントで検索できるようになります。うろ覚えのキーワードからでも、目的の文書や動画の該当箇所へすぐにたどり着けます。

LLM（大規模言語モデル）を設定すれば、要約、タグの提案、Q&A機能（Ask）も利用可能です。ただし、AIの回答がすべてではありません。生成された要約や引用は、あくまで「元のファイルの正しい場所へ素早く戻るための手がかり」として使うのが一番実用的だと考えています。

## 外部メディアの取り込み（Media Import）

YouTubeなどの外部動画も、ローカルファイルと同じように自分のライブラリへ取り込めます。

URLを貼り付けるだけでなく、チャンネルやプレイリストを購読して新しい動画を自動で集めることも可能です。タイトルやサムネイルだけでなく、字幕も一緒に保存されるため、外部の動画であってもローカルファイルと同じように検索や要約の対象になります。

「あとで見る」つもりでブックマークしたまま放置しがちなURLも、自分の録画やメモと並べて管理できる、検索可能なアーカイブへと変わります。

## ファイルとメモを紐付ける（Knowledge）

メディアファイルに関連付けて、Markdownでノートを残せる機能です。

ノートは普通のフォルダに保存されるため、ブラウザ上からでも、使い慣れた外部エディタからでも編集できます。ノートから動画の特定のシーンへリンクを張ったり、ノート同士を繋げたりすることで、ファイル群に文脈を持たせることができます。

単なる独立したメモ帳ではなく、「なぜその動画が重要だったのか」「どのファイルがどの資料の裏付けになっているのか」など、ライブラリ内の情報を整理し、関連付けるための場所として機能します。

## 主な活用法

- 動画、本、スキャン、個人ファイルのためのメディアサーバー。
- 講義、配信、トーク、ポッドキャスト、クリップをあとから探せるアーカイブ。
- 動画、テキスト、スクリーンショット、ノートを関連付けて扱う調査用ライブラリ。
- YouTubeチャンネルやプレイリストを集めながら、字幕や文脈を失わない保存場所。
- 要約、引用、Markdown ノートを元ファイルのそばに置けるローカルな知識ワークスペース。

## クイックスタート

必要環境: Docker、Python 3

```bash
git clone --recurse-submodules https://github.com/mamepenguin/Litloft
cd Litloft
python3 configure.py
docker compose up -d --build
```

`http://localhost:3000` を開きます。

同じLAN上の別デバイスからは `http://<host-ip>:3000` を開きます。

`configure.py` は、ローカルの Docker 設定、ドライブマウント、ポート、
任意のアドオンサービスを生成します。初回起動時はセットアップウィザードで
ドライブ名、アクセス制御、アドオンポリシーを設定します。

アップデート:

```bash
git pull --recurse-submodules
docker compose up -d --build
```
